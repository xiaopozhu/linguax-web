# Mac マウスのスクロールがカクつく？第三者マウスをスムーズにする方法

普通の**第三者マウス**（ロジクール、Razer、キーボード系メーカーのマウス）を Mac につなぐと、スクロールが**一段ずつジャンプする**ことに気づきます。長いページや長文ドキュメントをスクロールすると目も手も疲れる。錯覚ではありません——これが macOS のサードパーティマウスのホイールに対する標準動作です。

Mac のトラックパッドがなめらかに動くのは、macOS が**トラックパッド専用のピクセル単位スムーズスクロール**を用意しているからです。USB / Bluetooth のマウスをつなぐと、システムは「離散的な行スクロール」に戻り、1 ノッチで数行ジャンプします。

## なぜカクつくのか

- macOS は第三者マウスのホイール入力を**離散的な「ノッチ（notch）」**として扱い、連続的な移動として扱わない。
- スムージングがないため、1 ノッチで数行を一気に飛ばす → 見た目にカクつき・振動になる。
- App ごとに反応が違うので、同じマウスでも **Safari / Chrome、Xcode / VS Code、PDF ビューア** で手触りが変わる。

**macOS のシステム設定にはサードパーティマウス用のスムーズスクロール項目がない**ので、スクロールイベントを傍受してスムーズなカーブで再生する軽量ユーティリティを使うのが実際的な解決策です。

## LinguaX のスムーズスクロールで修正

LinguaX はネイティブな Mac アプリ（約 10MB、Electron なし、アカウント不要）で、マウスホイールの信号を書き換えます。核となるのは 3 段の細調整：

- **Min Step（最小ステップ）**——1 スクロールあたりの最小移動距離（デフォルト 33.6）。
- **Speed Gain（速度ゲイン）**——連続スクロール時の加速度（デフォルト 2.70）。
- **Duration（持続時間）**——1 スクロールごとのイージング時間（デフォルト 4.35）。

重要：**マウスホイールにだけ作用**し、トラックパッドの自然な滑らかさには手を出しません。さらにスムーズスクロールは **App ごとに ON/OFF** できます——ブラウザでは速く弾ませたい、コードエディタでは精密に位置決めしたい、それぞれ独立して設定できます。（3 段スライダーはグローバル、ON/OFF のみ App 別。）

## 設定手順

1. LinguaX をインストールし、初回起動時に**アクセシビリティ**権限を付与。
2. **Mouse+** を開き、まず**スムーズスクロールだけ**をオンにする。他はいじらない。
3. **ブラウザ、コードエディタ、PDF/長い画像ビューア**の 3 シーンでそれぞれ 1–2 分試す。
4. **一度に 1 段だけ調整**：先に Min Step、次に Speed Gain、最後に Duration。1 段調整後 2–3 分様子を見る。明らかに良くなれば残す、そうでなければデフォルトに戻す。

一度に複数段調整すると、どの値が効いているか分からなくなります——一番よくある落とし穴。

## それでもカクつく場合、まず 3 つ確認

- **複数のマウスユーティリティを同時に動かさない。** Mos、SteerMouse、Logi Options+、BetterMouse などを終了し、LinguaX 単独で再テスト。複数がスクロールイベントを傍受すると打ち合いになりフレーム落ちやイベント欠落が起きます。
- **App 別上書きは必要な場所だけに使う。** グローバルで自分に合った基準を保ち、本当に別の手触りが必要な App（動画編集ソフトなど）だけ個別上書き。
- **App を再起動してもう一度試す。** 一部の App は起動時にしかスクロールイベント設定を読まないため、変更後 relaunch すると安定します。

## ほとんどのユーザーへの推奨基準

- スムーズスクロールを有効化。
- Min Step / Speed Gain / Duration はデフォルト（33.6 / 2.70 / 4.35）のまま、違和感があれば動かす。
- App 別上書きは最小限、本当にカクつく 1–2 個の App だけ。

LinguaX は **Mac のスリープ / 復帰後**もスムーズスクロールを自動復元します。毎日手動でオンし直す必要はありません。

## よくある質問

### 特定のマウスにしか効きませんか？

いいえ。**USB / Bluetooth のどのマウス**でも動作、ドライバは不要です。認識される Logitech モデル（MX Master シリーズ、MX Anywhere、G502 X、M720、M585 など）ではデフォルトマッピングの最適化が追加されます。

### トラックパッドに影響しますか？

しません。スムーズスクロールは**マウスホイール信号のみ**を処理し、トラックパッドはシステムネイティブのパスを通るので手触りは変わりません。

### Mos、Mac Mouse Fix、LinearMouse との違いは？

Mos は無料でスムーズスクロール専門、LinearMouse は無料でポインタ加速専門、Mac Mouse Fix はジェスチャも追加。それぞれ良いですが、**スムーズスクロールもボタンマッピングも App 別動作も欲しい**なら 3 つ同時装は逆に打ち合いになります。LinguaX は 1 本のネイティブパイプラインでこれらを同時処理します。詳細は [Mac マウス増強ツール比較（英語）](/docs/comparisons/mos-vs-linearmouse-vs-mac-mouse-fix)。

### 無料ですか？

30 日間のフル機能無料トライアル、アカウント登録不要。以降は**買い切り $9.9、3 台まで利用可能**、サブスクリプションではありません。

### スリープ / 復帰後もスムーズは効きますか？

はい。LinguaX は復帰時に入力サービスをリフレッシュ、Bluetooth マウスは自動再接続され、スムーズスクロール状態は手動で戻す必要はありません。
